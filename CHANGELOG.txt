LegacyIsland 1.8.0.1 2026-10-05 更新日志（本版本仍在开发中，以下内容可能继续变动）：
1. 将应用从 .NET 6 迁移到 .NET Framework 4.7.2，发布包改为依赖本机 .NET Framework 运行，不再自带运行时
2. 界面框架全面从 MaterialDesign 迁移到 MahApps.Metro，窗口统一使用 MahApps 标题栏，图标改用 Segoe MDL2 与 RemixIcons
3. 设置界面重做为 Windows 10 风格：左侧汉堡导航、页面切换过渡动画、右侧设置抽屉、开关统一为 ToggleSwitch、精简设置项描述，默认窗口尺寸 867×640
4. 品牌更名为 LegacyIsland，更换应用图标，重做关于页面（插画 + 版本号 + 版权 + 官方链接），移除回声洞
5. 托盘右键菜单与设置标题栏按钮改用 Remix 图标并统一 MahApps 样式，窗口标题不再被强制大写
6. 消息类对话框（需要重启、各类删除/覆盖确认、退出确认等）改用 MahApps MessageDialog
7. 删除「隐私」设置页，并彻底移除 Sentry 及匿名使用分析相关代码
8. 版本号接入 git 提交实时生成（0.<Ship 提交数>.<yyMMdd>.<总提交数>+<短 hash>）
9. 打包：新增发布脚本，Release 构建后使用 Costura 打成单文件，产物更名为 LegacyIsland.exe，不再附带 exe.config
10. 打包：支持测试打包（Preview 包，AES-256 加密、文件名带实时版本号，便于分发内测）
11. 体积优化：默认不内置字体（改用系统字体，后续支持按需下载）、移除 gRPC、移除表情包、移除 Sentry，发布 exe 体积从约 59MB 压缩到约 8.7MB
12. 移除管理服务器 gRPC 长连接，跨进程 IPC 改用命名管道
13. 彻底移除首次启动引导（OOBE），启动后直接进入主界面
14. 修复从设置切换明/暗主题后托盘菜单配色不立即生效、需要重启才生效的问题
15. 移除「导入 Excel」与「导出到 Excel」相关功能（含拖拽表格文件导入）
16. 继续精简：不再把调试符号（pdb）嵌入 exe、移除 CodePages 依赖与各 NuGet 包的多语言卫星资源、移除集控服务端指令链及 protobuf 依赖
17. 禁用应用自动更新：移除设置页更新入口、托盘更新菜单与启动时的更新检查
18. 移除自定义 XAML 主题系统（主题市场、主题下载与打包相关功能）
19. 重做天气设置页：全出血 Hero 展示当前天气、逐日与逐小时预报，设置项内联；城市搜索改为内置 2500 余个中国地区的离线拼音与模糊搜索
20. 窗口设置增强：新增窗口层级检查频率、录制模式、阻止截图与显示器友好名，并重做页面布局
21. 修复设置窗口高度与导航分隔线、刷新显示器列表后下拉框未选中、关于页 Hero 图右侧 1px 白边等问题
22. 重做外观设置页：颜色选择统一改用 MahApps 内置 ColorPicker，新增「品牌色」主题色来源与字体预览（四种字号对照与字符样例）
23. 新增字体按需下载：主界面字体支持在「外观」页从云端字体清单下载到本地 Fonts 目录并选用，也支持手动放入字体文件；已安装的字体项自动禁用
24. 统一设置窗口抽屉样式：各页抽屉的标题、说明、内边距与宽度保持一致
25. 重做存储设置页：新增磁盘与 LegacyIsland 存储占用总览（分类占比条），备份区卡片化，新增缓存/日志/临时清理、打开目录与一键重置设置（保留档案与备份）
26. 修复：移除天气设置页末尾多余的跳转提示
