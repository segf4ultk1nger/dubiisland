# UIAccessX

为 ClassIsland2 带来超级置顶。

## 功能

- 超级置顶（基于 UIAccess，用的是 InkCanvasForClass Evolved 的方案）
- 以管理员身份重启 ClassIsland 和以管理员身份开机启动（来自 LegacyIsland）
- 主界面的超椭圆圆角支持（来自 LegacyIsland）
- 修改主界面缩放上限至 8.00x（来自 LegacyIsland）
- 屏蔽 Windows10 的触摸边缘手势（来自 InkCanvasForClass）

超级置顶在设置页面的“主页面”，“窗口”的“窗口层级”的折叠菜单中

其他设置自己去找，总找得到的。

如果需要禁用 UIAccessX，请前往“插件”页面，找到“刷新”按钮旁边的三个点按钮，在弹出的菜单中选择“禁用 UIAccessX 并重启”

## 注意

该插件如果检测到你安装了其他同类型的插件会自动禁用对应功能。
